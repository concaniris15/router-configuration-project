# router-configuration-project

A Cisco Packet Tracer project focusing on network topology design, router configurations, and IP addressing schemes.

## 📌 Project Overview
This repository contains the Packet Tracer topology file (`router.pkt`) for a router configuration project.

## 🛠️ Features & Setup
- Custom router configuration and interface routing setups.
- Subnetting and network network layout.
- Cisco Packet Tracer configuration file included.

## 📁 File Included
- `router.pkt` - Main Cisco Packet Tracer file.
